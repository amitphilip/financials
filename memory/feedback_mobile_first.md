Design all UI mobile-first.

**Why:** User explicitly requested mobile-first design for this app.

**How to apply:** Use min h-12 for interactive elements, readable font sizes (min text-sm), px-4+ horizontal padding, `min-h-svh` instead of `min-h-screen`. Generous spacing throughout. Apply to all new and modified UI components. Numbers are visible by default (`hidden: false` in NumbersProvider).
